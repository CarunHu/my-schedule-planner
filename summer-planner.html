📱 安装到手机

⚠️ 重要前提
你必须先把本文件部署到 GitHub Pages（或任意网页托管），手机和电脑都通过 同一个网址（如 https://xxx.github.io/xxx/summer-planner.html）打开，才能实现数据同步。如果手机上打开的是本地文件（file:///...），数据无法同步！

📌 第一步：部署到 GitHub Pages

1️⃣ 把 summer-planner.html 和 manifest.json 两个文件上传到你的 GitHub 仓库
2️⃣ 进入仓库 Settings → Pages → Source 选 main 分支
3️⃣ 保存后会生成一个网址（如 https://你的用户名.github.io/仓库名/summer-planner.html）

📱 第二步：手机安装到桌面

1️⃣ 用手机浏览器（QQ浏览器/Chrome/Safari）打开上面的 GitHub Pages 网址
2️⃣ QQ浏览器：点右下角「⋮」→「工具箱」→「添加快捷方式」→「手机桌面」
2️⃣ Chrome：点右上角「⋮」→「添加到主屏幕」
2️⃣ Safari：点底部分享按钮 →「添加到主屏幕」
💡 安装后桌面会出现图标，点击打开就像一个真正的 APP。
⚠️ 注意：安装的是网页书签，每次打开会访问 GitHub Pages 上的文件。如果更新了 HTML 文件并推送到 GitHub，下次打开手机就会自动使用最新版本。

☁️ 云端同步

☁️ 前提条件
必须先用 GitHub Pages 部署本页面，手机和电脑通过同一个网址访问，然后在此配置同步。如果手机打开的是本地文件，数据无法同步。

第一步：获取 JSONBin 密钥

1️⃣ 浏览器打开 jsonbin.io 并登录
2️⃣ 点击右上角头像 → Access Keys
3️⃣ 复制页面最上方的 X-MASTER-KEY（以 $2a$10$ 开头）
⚠️ 用 X-MASTER-KEY（最上面那个），不要用 X-ACCESS-KEY（下面 PLANNING 那个）

第二步：填入密钥并连接

💡 怎么获取 Bin ID？
在电脑上点过「创建云存储」后，设置页会显示 Bin ID（如 6xxxxxxxfxxxx），复制过来即可。手机上留空就会创建新的数据桶，导致数据不同步！
